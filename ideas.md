# Chosen Direction: Crimson Signal

## Design Movement
**Techno-editorial brutalism softened by high-end instrumentation design.** The site uses the severity of a security workstation, balanced with an editorial rhythm that makes the professional story easy to scan.

## Core Principles
1. **Signal over spectacle:** Every red highlight carries meaning—availability, a node, a connection, or a project state.
2. **Asymmetric narrative:** Content lives in a left utility rail and staggered right-hand panels, never a generic centered-card stack.
3. **Data made human:** Technical motifs appear as subtle diagrams, terminal snippets, and disciplined labels, while the writing stays direct and grounded.
4. **Tactile restraint:** Borders are thin, surfaces layered, and motion directional; nothing is decorative without a job.

## Color Philosophy
The base is almost-black graphite to establish privacy, focus, and contrast. **Signal Maroon (#A32035)** acts as the ownable warning-light accent, used sparingly against ivory type (#F4F0E8) and softened slate metadata. The effect is less neon-cyberpunk and more a calibrated security console in a dimly lit lab.

## Layout Paradigm
A persistent vertical **signal rail** anchors the desktop experience. Sections break out from it in alternating horizontal bands, with oversized vertical labels, framed content modules, and off-axis decorative diagrams. On smaller screens, the rail becomes a compact progress marker and the content collapses into a readable single flow.

## Signature Elements
1. **Signal rail:** A thin vertical rule with numbered section positions and an illuminated active node.
2. **Protocol panels:** Dark layered cards with clipped corner details, monospace metadata, and hairline maroon separators.
3. **Telemetry traces:** Animated node paths and small waveform/data-grid marks that support the technical tone without overpowering copy.

## Interaction Philosophy
Interactions should feel like operating an instrument: precise, responsive, and consequential. Project cards tilt by a few degrees, terminal tabs switch instantly, and modal details enter as a focused inspect panel. Hover states brighten borders and pull information forward rather than merely changing colors.

## Animation
Entrance motion uses a 560ms staggered opacity-and-translate reveal with a custom ease-out. Telemetry traces drift slowly only when reduced motion is not requested. The hero terminal types through a short analysis sequence, while project card highlights respond within 180ms. All motion respects `prefers-reduced-motion` and avoids continuous distracting loops.

## Typography System
**Space Grotesk** is the display face: wide, assertive, and technical for names and section headings. **Manrope** supports readable body copy and project descriptions. **IBM Plex Mono** handles labels, technical badges, dates, terminal content, and navigation counters. Large headings use a tight negative letter-spacing; all metadata remains uppercase with generous tracking.

## Brand Essence
**A security-minded AI/ML portfolio for early-career teams seeking practical, grounded problem-solving.**

Personality: **deliberate, analytical, resilient.**

## Brand Voice
Headlines are concise and outcome-oriented; CTAs use direct verbs; microcopy is precise and low-hype.

Example lines:
- “Turning data, code, and security into practical solutions.”
- “Inspect the systems I am building.”

Avoid generic filler such as “Welcome to my website” or “Get started today.”

## Wordmark & Logo
The mark is an abstract **R / shield / data-path glyph**: a broken maroon shield with a diagonal inner path that resembles an `R` and a protected network route. It uses no text, works at favicon scale, and pairs with the wordmark in Space Grotesk.

## Signature Brand Color
**Signal Maroon — #A32035**

## Style Decisions

- Every major section attaches visibly to the numbered signal rail so the page reads as one connected analytical dossier.
- Signal Maroon appears only on active nodes, CTAs, project and security states, key numerals, and one intentional emphasis word per section; ivory holds the primary hierarchy.
- The R/shield/data-path glyph recurs in navigation, footer, and telemetry diagrams to create a recognizable ownable mark.
